# TypeScript Configuration

A shareable TypeScript configuration.

## Usage

Add the configuration to your `tsconfig.json`:

```json
{
    "extends": "@apst/tsconfig"
}
```

Or for a library:

```json
{
    "extends": "@apst/tsconfig/lib"
}
```

### TypeScript 5

For TypeScript 5, please use the following configuration:

```json
{
    "extends": "@apst/tsconfig/5"
}
```

Or for a library:

```json
{
    "extends": "@apst/tsconfig/5/lib"
}
```
